# Relief valve traveler: print in the ValveKeep (VSI) form layout

## Goal

The new relief valve template "Traveler - Relief Valve (ValveKeep form)" (job type `repair`, valve type `Relief Valve`) must print as a filled-in copy of the ValveKeep "Relief Valve Service Traveler" form: same two pages, same sections, same order, same cell positions. After those two pages it prints photo pages for as-found and as-left pictures. The reference form is at `docs/reference/VSI Repair Traveler.pdf`. Open it and match it; the written spec below is a transcription and the PDF wins where they differ.

Today "Print traveler" in `src/components/ItpTravelerReportPanel.tsx` prints a generic step-by-step list (`PrintStepBlock`, `window.print()`). Keep that. Add the form print as a second option.

## What already exists

The template is built the same way as "Traveler - Twinseal": a short ITP of 12 work steps plus the standard parts-order step, with all data entry behind each step's traveler button. It is generated by `scripts/generate-traveler-templates.py`, entry `T["u"]`, and loaded with `supabase/add-itp-traveler-relief-valvekeep.sql`. Read `T["u"]` first; it lists every field.

**The rule that must not be broken.** ValveKeep data will later be migrated to another database, so it has to stay cleanly separable from anything J-S adds:

- A field whose id contains `vk_<key>` is one cell on the ValveKeep form. Ids look like `trv_u_02_vk_set_pressure`; the form key is the part from `vk_` onward and does not depend on the step number.
- A field whose id contains `js_<key>` is a J-S addition that is not on the ValveKeep form (today: `js_replaced_as_found`, `js_replaced_as_left`).
- Never rename, repurpose or remove a `vk_` key. Anything new that is not a cell on the reference form gets a `js_` key.
- The two form pages print `vk_` data only. `js_` data and photos print on the pages after them.

The older 40-line "Valve Keep Template" stays exactly as it is. Do not edit, migrate or delete it.

Steps and what each holds:

| Step | Form section |
|---|---|
| Receive valve and record basic information | header, ID block, Received Data; step photos = as-found |
| Record valve data plates | valve data, Original Nameplate (`vk_onp_*`), Previous Repair Nameplate (`vk_prn_*`), Previous Test Only Plate (`vk_pto_*`) |
| Pre-test | Pre-Test Data |
| Disassemble and clean | Disassembly (`vk_dis_*`) |
| Parts inspection | disposition line, Parts Details (`vk_pd_<part>_cond|cond2|work|rec`), replaced-part photos (`js_`) |
| Critical dimensions | `vk_cd_<row>_found|mfg|mach|shipped` |
| Machine and lap | Cleaned / Machined / Lapped / Instrument Used |
| Assemble | Assembly (`vk_asm_*`), Parts Description (`vk_pdesc_<n>_name|number|heat`), Torque Wrench #, Assembled By |
| Set and test | Test Data |
| Seal, tag and stamp | closing checklist (`vk_chk_*`), Reset Only |
| Paint and prepare for shipping | Painted, Packed By; step photos = as-left |
| Final inspection | Final Insp / QC, Cust Notes, Comments, JS Comment |

## How this app already does a customer-exact form

`src/lib/pcmsFormPrint.ts` builds the Phillips 66 PCMS form as standalone HTML and opens it through `openPreviewWindow` / `showHtmlPreview` in `src/lib/printHtml.ts`. Build the new form the same way: one function that takes the traveler data and returns a complete HTML document with its own print CSS, Letter portrait. `buildItpTravelerReport(plan)` in `src/lib/itpTravelerReport.ts` already returns every step with its fields, values and photos.

## What to build

### 1. The form print

`src/lib/reliefValveServiceTravelerPrint.ts`: look up each cell's value by its `vk_` key (match the field id from `vk_` onward) and lay out the two pages per the spec below. Empty cells print as blank lines so a blank traveler can be printed and filled by hand.

Show a "Print ValveKeep form" button beside "Print traveler" on the traveler page and in the template preview whenever the plan contains `vk_` fields.

### 2. Table entry for the three table blocks

Parts Details (37 rows by 4 codes), Critical Dimensions (11 rows by 4 columns) and Parts Description (6 rows by 3 columns) are stored as ordinary fields with the id patterns above. In `src/components/ItpTravelerStepModal.tsx` they currently render as a long flat list. Render fields that follow those id patterns as compact tables instead: one row per part or dimension, one column per code or measurement. Do not change how the values are stored.

### 3. Replaced-part photos

On the Parts Details table, when a row's Work code is "1- Replaced", require at least one as-found photo and one as-left photo for that part. Store them per part under `js_` ids (for example `js_pd_<part>_found` and `js_pd_<part>_left`), and allow optional photos on any other row. Once that works, drop the two generic fields `js_replaced_as_found` and `js_replaced_as_left` from `T["u"]`.

If you change `T["u"]`, re-run the generator, rebuild `supabase/add-itp-traveler-relief-valvekeep.sql` as an update of that one template row, and paste the SQL in chat.

## Form spec

Branding: where the reference shows the VSI logo and "Valve Sales Inc.", print the J-S Machine & Valve logo and name. "VSI Shop ID" becomes "JS Shop ID" and "VSI Comment" becomes "JS Comment". Put these strings in one constants block. Everything else matches the reference.

For choice cells (Yes / No, Good / Fair / Dirty / New and the like) print all choices as the reference does and circle or bold the selected one.

### Page 1

**Header.** Logo; company name; title "Relief Valve Service Traveler"; "Hazardous Service: Y / N"; Owner; Plant; Traveler Type; Due Date (red); "Field Service | Yes / No".

**ID block.** JS Shop ID, Customer PO, Tag Number, Equip. Location, Work Performed, Unit / Vessel, SAP / Asset.

**Valve data.** Manufacturer, Service, Model Number, S/N. Then three columns:
- Valve Size, Set Pressure, Capacity, Dual NP Capacity, Req'd Code, Temperature, Lift / RL (checkbox plus two values split by "/"), Cold Diff Set
- Inlet, Orifice Desg., Body Material, Bonnet Material, Bellows Material, Spring Number, Spring Material, Back Pressure
- Outlet, Orifice Area, Trim Material, Soft Seat Material, Cap Type, From / To

**Original Nameplate.** XXX'ed Out? Yes / No; Model Number; Set Pressure; Temperature; Capacity; CDTP; Code Stamp; Assembled By & Date/Code; BP.

**Previous Repair Nameplate.** Model Number; Set Pressure; Temperature; Capacity; CDTP; Repaired By; Prev VR #; I.D.#; BP; Prev Repair Date; Prev VR Stamp Yes / No.

**Previous Test Only Plate** (boxed, right side). PTO Company; PTO Date; PTO ID#; Prev T/O Stamp Yes / No; Prev T/O Set.

**Received Data.** DUE DATE; Date Received; Work Performed; As Found Condition (Good / Fair / Dirty / New); Received By; Set Press Changed Yes / No; Special Cleaning Yes / No; Conversion Yes / No; Nameplate (Original / Dup / Miss / Illegible); Seal (Intact / Broke / Missing).

**Pre-Test Data.** Pretest Yes / No; Popped @ ___ PSIG; Back Pressure Test; Bellows Test; Pretest By; Leak Test ___ @ ___; Tight / BPM / Moderate / Excessive; Pretest Comments.

**Disassembly** (left). Compression Screw; Upper Ring; Lower Ring; Inspected By; Instrument #; As Rec - Spring #; As Rec - Spring Range.

**Critical Dimensions** (right; columns As Found, Mfg, Mach. By, As Shipped). Nozzle Min; Noz Seat Step Min; Bore Dia. Min; Disc Min Thickness Min; Disc Inside Step Min; Disc Outside Step Min; Disc Holder OD Min; Guide ID Max; Guide Clearances Max; Spindle Run Out; Base Top to Nozz Max.

### Page 2

**Header.** "Relief Device Service Traveler (Page 2)"; Tag Number; JS Shop ID #; S/N.

**Parts Details** (left column; heading "Cond. Code / WK / Rec"; 4 boxes per row: condition, condition 2, work, recommendation; print the code letter only). Body; Bonnet/Yoke; Nozzle; Spring; Disc; Disc Holder; Guide; Spindle; Spindle Retainer; Cap; Lever; Comp Screw; Upper ADJ Ring; Upper Ring Pin; Lower ADJ Ring; Lower Ring Pin; Bolts/Studs/Nuts; Up Spring Washer; Low Spring Washer; Gasket Set; ORing; MFG Name Plate; Inlet Condition; Inlet Flange Face; Outlet Condition; Out Flange Face; Bellows; Bug Vent; Disc Collar; Lift Stop; Overlap Collar; Lift Washer; Thrust Bearing; Soft Goods Kit; Limit Washer; then 2 write-in rows.

**Code legends** (printed beside the parts list).
- Condition Codes: A- Good; B- Bent; C- Broken; D- Stm Cut; E- Cracked; F- Collapsed; G- Corroded Mild; H- Corroded Severe; I- Deposits Light; J- Deposits Heavy; K- Eroded; L- Galled; M- Incorrect; N- NonOEM; O- Missing; P- Out Of Tolerance; Q- Pitted; R- Plugged; S- Poor; T- Worn; U- Scored; V- Leaks; W- Req's Replacing; Y- Seized; e- Threads Stripped.
- Work Codes: 0- Cleaned; 1- Replaced; 2- Machined/Lapped; 3- Machined; 4- Lapped; 5- Polish; 6- Left; 7- Repaired.
- Recommendations: [- Replace Next Repair; ]- NDT/NDE Next Repair; #- Replace ASAP; *- Machine NOH.

**Disposition line** (top right). Checkboxes OK To Proceed, NETR - Replaced, NETR - Scrapped; By; Date.

**Assembly.** Checkboxes: Nozzle Tight; Bellows Tight; Disc Collar -2; Bonnet Tight; Required Gaskets Installed; Up Adj. Ring - Set ___ (Turns / Notches / Inches / NA); Low Adj. Ring Set ___ (Turns / Notches / NA); Overlap Collar Set & Sealed ___.

**Parts Description.** Table: Part Name, Part Number, Heat #.

**Below the table.** Torque Wrench #; Assembled By; Cleaned; Machined; Lapped; Instrument Used; Painted.

**Test Data.** Set Pressure; CDTP; BP; Suggested BD; Test Method (Bench / ALD / H/L / N2 / Live / Inline); Test Stand ID; Test Media (Air / Water / Steam / N2); ALD Equip ID; Load Cell #; 1st, 2nd, 3rd Test Press, each with its Reseat Pressure; Final Test Pressure with Reseat Pressure; Leakage Rate ___ @ ___; Measured Lift; BP Test (Yes / No / NA) @ ___; Cust Gauge Cal; Gauge 1 S/N; Date Tested; Tested By; Witnessed By.

**Closing checklist** (bottom left; each Yes/No/NA). VK Entry; Disassembled; Plate Made; Plate Checked; VR Stamped; T/O Stamped; Valve Tagged; Valve Sealed.

**Bottom line.** Reset Only: X'd MFG Plate (checkbox); Final Insp / QC; Packed By.

**Footer.** Cust Notes; Comments; JS Comment; "Page 2 of 2".

### Page 3 onward: J-S additions

- "As-Found Photos": step photos from "Receive valve and record basic information" and "Disassemble and clean".
- "Replaced Parts": each replaced part's name with its as-found and as-left photos side by side.
- "As-Left Photos": step photos from "Paint and prepare for shipping".
- Any other `js_` field that has a value, listed by label.

Caption each photo with its step or part name. Leave a section out when it is empty. Number these pages after "Page 2 of 2" without changing that footer.
